## 1. Prioritized List of Improvements (Layout & Responsive)

Our QA audit surfaced several high-impact layout issues that require immediate patching:

1. **Mobile Overflow:** The `.info-grid` uses `minmax(300px, 1fr)`. On mobile viewports under 350px (e.g. 320px minus 48px padding), the hard `300px` minimum forces a horizontal scroll. 
   - *Fix:* Update grid template to `minmax(min(100%, 300px), 1fr)`.
2. **Hero Vertical Rhythm Slack:** The 213px of vertical slack in the Hero section is caused by the hero image respecting its intrinsic aspect ratio in normal document flow. At wide viewports, the image inflates the row height past the CSS `min-height`.
   - *Fix:* Pull the image out of document flow using `position: absolute; inset: 0` inside `.hero-media`. This will force the section to snap to the `.hero-content` natural height.
3. **1024px Grid Orphans:** At 1024px, the `.values-grid` drops from 5 columns to 3. This leaves 2 awkwardly orphaned cards left-aligned on the bottom row. 
   - *Fix:* Drop directly from 5 to 2 columns (or 4), or use flex wrap with center justification.
4. **Hero Gradient Seam:** At `max-width: 860px`, the `.hero-media::before` gradient falls back to `var(--mint)`. It must use `var(--mint-hero)` to correctly blend the visible seam.

> **Note on Text Measure:** The text columns correctly respect the `26em` measure limit requested. They are not too wide.

## 2. Motion Proposal

To adhere to the "Architecture of Authenticity" and avoid generic SaaS "AI Slop" (e.g., standard opacity fade-ins on scroll), we propose a zero-structural-motion approach:

- **What Stays Still:** The Hero panel, layout columns, and typography blocks. We explicitly advise *against* letter-by-letter reveals for Balmoral, as CSS transitions physically break the script's cursive joining while animating.
- **What Moves (Micro-Interactions):**
  - **Philosophy Geometries/Comb Device:** Draw the SVG strokes over 1.2s using `stroke-dashoffset` path-reveals when entering the viewport. This emphasizes a crafted, analog feel.
  - **Buttons (Feedback):** Enhance hover states with a chamfered `-2px` Y-translation and an inset pseudo-element sweep. Keep text scale completely static.

## 3. Fidelity to the InDesign PDF

**Fidelity Assessment:** Extremely High. 
The current implementation successfully avoids the generic template aesthetic. The layout relies entirely on flat editorial columns with no shadows, borders, or elevated cards. 

**However, we recommend one aesthetic purge:**
- **The Cream Section:** The use of alternating warm section backgrounds (`--cream`) signals a generic AI-generated template. We strongly recommend purging `--cream` and forcing `--white` to maintain the stark editorial layout seen in the InDesign philosophy section.
- **Brand Device:** We strongly recommend implementing the unused "comb silhouette" from the InDesign file as the footer divider, replacing the generic circular SVG currently in place.

### 🔴 Conflicts & Failures (Requires Decision)
- **Balmoral Horizontal Scale (130%):** **Fail**. The CSS is currently using `balmoral-a9.woff2` (100% width). To fulfill Diana's request, the CSS font-face must be swapped to map to the `balmoral-a9-wide.woff2` variant.
- **Balmoral Letter Joins (Tracking):** **Conflict**. Diana requested wider letter spacing for legibility. However, as noted in the brief, adding positive `letter-spacing` to Balmoral will shatter the connected cursive glyphs. We will enforce `letter-spacing: 0` on Balmoral and apply wider tracking strictly to Alegreya prose.
- **Background Images for "Life":** **Conflict**. Diana requested background photography to give the site more life. Applying background images directly conflicts with the strict "bare text columns on white" mandate from the InDesign PDF and destroys legibility. 
  - *Recommendation:* Reject background imagery behind text. Maintain stark white/hex grounds, and instead introduce "life" through high-quality photography in dedicated gallery blocks and the SVG motion reveals proposed above.
